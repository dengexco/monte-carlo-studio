COURSE NOTES · PAGES 61–66

Methods & course guide

Based on I-Stochastic Processes.pdf, Manisa Celal Bayar University, Industrial Engineering. Page numbers below refer to the supplied 67-page lecture PDF.

01 / What are we learning?

Repeated random sampling can estimate a known quantity. The known values of π and e let us measure accuracy. Increasing the sample size usually improves stability, but does not guarantee a smaller error in every individual run.

Course settings (p. 61): n = 10, 100, 1,000, 10,000; five independent runs per n and per experiment. This gives 40 estimates. The interface also permits exploratory settings; the indicator below checks whether the current run uses the course settings.

Run an experiment to see its settings.

02 / Estimating π — page 62

  1. Generate independent uniform coordinates X and Y in the unit square.
  2. Count a point as inside when X² + Y² ≤ 1.
  3. After n points, multiply the inside fraction by four.
  4. Repeat the whole calculation five times for each n.
π̂ = 4 × Ninside / n

The quarter circle has area π/4 inside a square of area 1. For illustration, 79 inside points out of 100 give 4 × 79 / 100 = 3.16. This is an example, not a fixed simulation result.

03 / Estimating e — page 64

  1. Start a trial with sum S = 0 and counter N = 0.
  2. Draw U uniformly, add U to S, and increase N by one.
  3. Continue until S > 1. Equality is not enough.
  4. Record N, reset S and N, and repeat for n trials.
  5. Average these n counts to obtain one estimate. Perform five complete runs for each n.
ê = (N₁ + N₂ + … + Nₙ) / n

For example, 0.40 + 0.35 + 0.50 exceeds 1 after three draws: record 3, not 1.25. The expected count is e. Here n counts complete trials; N counts draws within one trial.

Code mapping: Estimate uses a fresh sum for each trial. Its count accumulates all draws across those trials; dividing by n equals the mean of the individual counts. This is the same estimator as the slide.

04 / Required tables — pages 63 & 65

These live tables follow the lecture format: one row per n, all runs side by side, mean, and reference. Only completed groups appear. With exploratory settings the number of run columns follows your selection.

The lecture displays references rounded to 3.14159 and 2.71828. Error calculations use Go’s higher-precision constants.

05 / Reading accuracy & stability

Mean: the average of the five estimates for one n. Absolute error: the distance between that mean and the reference. Sample SD: spread between runs, using a divisor of runs − 1. SD is not a confidence interval or standard error.

The Law of Large Numbers (p. 15) explains convergence of averages. The accuracy discussion (p. 48) gives the typical standard-error scale 1/√n. Approximately halving it needs four times as many trials. More trials therefore cost more computation; an individual error can still increase by chance.

06 / Final discussion — page 66

Use your actual results to answer these questions; the guide explains what to inspect rather than inventing conclusions.

  1. Which n has the greatest variation? Compare the spread or SD across runs separately for π and e. Do not assume the smallest n must always win.
  2. How does n affect accuracy and stability? Compare both absolute error and SD across n. Distinguish the general tendency from any exceptions in your data.
  3. Why can equal-n runs differ? They use different pseudo-random streams and therefore sample different points or sequences.
  4. How does this relate to the Law of Large Numbers? Larger within-run samples make the averages tend toward the corresponding expected values.
  5. What would much higher accuracy cost? More trials and computation; roughly four times the sample size for half the typical standard error.

07 / Implementation & submission scope

The numerical methods match pages 62 and 64. Each (seed, experiment, n, run) combination initializes a separate PCG stream. Repeating the same settings reproduces the result; a different run uses a different initialization. The notes do not prescribe PCG or a particular seed.

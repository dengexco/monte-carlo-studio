# Monte Carlo Studio

Interactive local Python application for estimating π and Euler’s number e through Monte Carlo simulation. Includes configurable experiments, interactive charts, replication tables, and CSV/JSON exports.

## Run

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python odev.py
```

The app opens in your browser and starts the default experiment automatically.

See [read.md](read.md) for the detailed Turkish code explanation, methodology, controls, and tests. Third-party asset sources are documented in [SOURCES.md](assets/vendor/SOURCES.md).
